# Inferencia Estadística

Este proyecto aplica herramientas de estadística descriptiva e inferencial utilizando Python.

## Objetivos

- Crear y analizar un conjunto de datos de estudiantes.
- Obtener estadísticas descriptivas.
- Analizar la distribución del nivel de satisfacción.
- Construir un intervalo de confianza del 95%.
- Realizar una prueba de hipótesis sobre la satisfacción promedio.

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy

## Metodología

El proyecto genera una muestra simulada de 200 estudiantes y analiza variables como edad, satisfacción y horas de estudio semanales.

Posteriormente se construye un intervalo de confianza y se realiza una prueba t de una muestra para evaluar:

H0: μ = 7

H1: μ ≠ 7
