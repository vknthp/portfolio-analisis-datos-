# Portafolio de Análisis de Datos

Este repositorio reúne proyectos desarrollados durante mi formación en análisis de datos, utilizando Python y herramientas de análisis estadístico y visualización.

## Proyectos

### 1. Análisis exploratorio de videojuegos
Análisis y visualización de datos de videojuegos mediante Pandas, Seaborn y Matplotlib.

### 2. Inferencia estadística
Aplicación de estadística descriptiva, intervalos de confianza y pruebas de hipótesis utilizando Python.

## Herramientas utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
