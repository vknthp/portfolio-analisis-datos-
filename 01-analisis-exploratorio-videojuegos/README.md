# Análisis Exploratorio de Datos de Videojuegos

Este proyecto presenta un análisis exploratorio de un conjunto de datos de videojuegos.

## Objetivos

- Analizar las relaciones entre las variables de ventas.
- Comparar los puntajes de crítica entre plataformas.
- Analizar las correlaciones entre variables numéricas.
- Comparar las ventas globales promedio según género.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn

## Análisis realizados

- Pairplot de variables numéricas.
- Gráfico de violín del puntaje de crítica por plataforma.
- Matriz de correlaciones mediante heatmap.
- Cálculo de ventas globales.
- Comparación de ventas globales promedio según género.
